# Freixo AI — Backend API

Serviço de backend em Node.js para o ecossistema **Freixo AI**.

## 📁 Estrutura

```text
backend/
├── src/
│   ├── app.js             # Ponto de entrada do backend
│   ├── controllers/       # Controladores de regras de negócio
│   ├── routes/            # Definição de rotas HTTP
│   └── services/          # Serviços e integrações
├── package.json           # Configuração de scripts e dependências
└── README.md
```

## 🚀 Execução Local

```bash
cd backend
npm install
npm start
```
